# n8n-coding-agent-sandbox
Private sandbox repository for n8n exercise 2 coding-agent workflow.

## دکمه ورود (Login Button)
این پروژه شامل یک دکمه ورود (Login Button) مدرن، زیبا و واکنش‌گرا است که به کاربران امکان می‌دهد فرآیند ورود به سیستم را به صورت تعاملی تجربه کنند.

### ویژگی‌های دکمه ورود:
- طراحی مدرن و مینیمال با استفاده از CSS نوین
- افکت‌های انیمیشنی جذاب هنگام نگه‌داشتن موس (Hover Effects)
- کاملاً واکنش‌گرا (Responsive) و بهینه‌سازی شده برای نمایشگرهای موبایل و دسکتاپ
- پیاده‌سازی استاندارد و دسترسی‌پذیر (Accessibility)

## راهنمای اجرای فایل HTML

برای اجرا و مشاهده دکمه ورود در مرورگر خود، مراحل ساده زیر را دنبال کنید:

### روش اول: اجرای مستقیم (ساده‌ترین روش)
1. فایل‌های پروژه را دانلود یا مخزن را کلون کنید:
   ```bash
   git clone https://github.com/your-username/n8n-coding-agent-sandbox.git
   ```
2. به پوشه پروژه بروید.
3. روی فایل `index.html` دوبار کلیک کنید تا در مرورگر پیش‌فرض شما (مانند Chrome، Firefox، Edge یا Safari) باز شود.

### روش دوم: استفاده از افزونه Live Server در VS Code
1. پوشه پروژه را در نرم‌افزار **VS Code** باز کنید.
2. افزونه **Live Server** را از بخش Extensions نصب کنید.
3. روی فایل `index.html` راست‌کلیک کرده و گزینه **Open with Live Server** را انتخاب کنید.
4. پروژه شما در آدرس محلی (معمولاً `http://127.0.0.1:5500`) به صورت زنده و با قابلیت آپدیت خودکار اجرا خواهد شد.
